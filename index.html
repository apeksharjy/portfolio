// flagship project

Smart journey

Travel & Ticket Booking

Booking travel shouldn't feel like a full-time job.

Smart journey is a travel and ticket booking application — my primary project so far — built to bring search, booking, and confirmation into one simple flow. It's where I've applied core programming concepts to a problem people actually run into.

Problem

  • Scattered booking flows across platforms
  • No single view of trip options
  • Manual, repetitive ticket steps

What it does

  • Search & browse travel options
  • Book tickets in a guided flow
  • Structured, reusable core logic

Built with

  • Java (core logic)
  • HTML (interface)
  • Fundamentals of DS & problem solving
